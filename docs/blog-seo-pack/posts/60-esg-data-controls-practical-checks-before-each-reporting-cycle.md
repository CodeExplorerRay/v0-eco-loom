# ESG Data Controls: Practical Checks Before Each Reporting Cycle

**Status:** Ready to Publish

ESG data controls do not need to begin as a complex audit program. A small set of repeatable checks can prevent common issues such as missing sites, duplicate files, unexplained unit changes, and calculations with no visible reviewer.

The right controls depend on the organization’s reporting purpose and risk. Start with the points where errors are likely and consequential, then make ownership explicit.

## Control the source-to-record path

For each data stream, define who submits the source, where it is stored, which fields are required, and who checks it. Use stable identifiers for sites, periods, and activities so records can be traced across systems. Keep the original source file alongside any transformed data.

A simple completeness check should confirm that every expected owner or facility submitted something, including a documented “no activity” response where appropriate.

## Add validation checks to the workflow

Set rules for accepted units, date ranges, duplicate identifiers, missing values, and unexpected changes. Use thresholds to flag records for human review rather than automatically deleting them. Explain how exceptions are resolved and how the correction is recorded.

For calculations, retain the factor, method, conversion, and version used. A reviewer should be able to follow a sample from source record to reported total.

## Separate preparation and review

Where practical, the person who prepares a material calculation should not be its only approver. Define review responsibilities and capture sign-off with date and scope. If team size makes full separation difficult, use compensating review steps and record them.

Do not mistake a checked box for evidence that the underlying record was examined.

## Reassess controls after changes

New systems, acquisitions, revised methods, and staff turnover can weaken controls that previously worked. Review the control list after material process changes and at the end of each cycle. Track failures and assign owners for remediation.

**Key Takeaway:** Effective ESG data controls make completeness, validation, review, and correction visible across the source-to-report path.
