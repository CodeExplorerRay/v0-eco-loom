# Report Depth Roadmap

## Phase 1
- Done: Build a shared report analytics service for:
  - emissions by scope
  - emissions by source type
  - emissions by department
  - verified vs unverified counts
  - evidence coverage
  - override counts
- Done: Surface analytics in:
  - report detail view
  - PDF report output
  - verifier CSV/JSON package

## Phase 2
- Done: Add report methodology metadata:
  - reporting standard
  - factor source policy
  - GWP basis
  - override policy
  - methodology notes
- Done: Add reporting boundary metadata:
  - business units included
  - departments covered
  - exclusions
  - reporting owner

## Phase 3
- Done: Add richer visual report sections:
  - scope contribution chart
  - source-type contribution chart
  - department leaderboard
  - monthly trend chart
- Done: Add intensity metrics when denominator data is available:
  - emissions per employee
  - emissions per revenue
  - emissions per facility
  - emissions per $1M tracked department budget

## Phase 4
- Done: Add assurance-oriented appendices:
  - evidence register
  - factor register
  - override register
  - unresolved data-quality issues
  - verifier export manifest

## Phase 5
- Done: Add configurable report generation options:
  - internal management view
  - verifier-ready view
  - board-ready summary
  - annual disclosure format
